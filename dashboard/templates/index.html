🌟 Hệ Thống Music Data Collector Studio Là Gì?

            

              Đây là hệ thống thu thập, trích xuất siêu dữ liệu (Metadata), đồng bộ lời bài hát Karaoke (.lrc) và tải âm thanh chất lượng cao 320 kbps MP3 tự động phục vụ nghiên cứu âm nhạc và đồ án tốt nghiệp. Hệ thống được triển khai trên máy chủ đám mây Oracle Cloud với cơ sở dữ liệu MongoDB lưu trữ vĩnh viễn.
            

          


          
🔄 Quy Trình Hoạt Động 3 Giai Đoạn Chuẩn Hóa:

          

            

              
1. Thu Thập (Sourcing)

              

                Cào dữ liệu từ 12 thể loại, theo tên ca sĩ, album, link Spotify, hoặc từ bảng xếp hạng ZingMP3 / Nhaccuatui. Cho phép lọc xem trước trước khi lưu vào MongoDB.
              

            

            

              
2. Xử Lý & Tải (Processing)

              

                Tự động đối chiếu nguồn âm thanh chuẩn 320 kbps, nhúng thẻ nhạc ID3 quốc tế (tên bài, ca sĩ, album, ảnh bìa HD) và tải lời bài hát có khớp thời gian (.lrc).
              

            

            

              
3. Quản Trị & Khai Thác

              

                Nghe thử trực tiếp với trình phát In-App Player có sóng nhạc, thanh tra toàn diện cây siêu dữ liệu, xuất file CSV/JSON và phân quyền nhóm làm việc.
              

            

          

        


        
        

          

            
🔑 Tại Sao Cần Cấu Hình Spotify?

            

              Spotify là kho dữ liệu chuẩn mực nhất thế giới về mã định danh âm nhạc quốc tế (mã ISRC), độ phổ biến (Popularity 0-100), ảnh bìa độ phân giải cao và phân loại nghệ sĩ.
            

          


          
📌 Phần 1: Lấy Developer API (Client ID & Client Secret) - Hoàn Toàn Miễn Phí

          

            

              Bước 1: Truy cập trang Spotify Developer Dashboard tại: https://developer.spotify.com/dashboard và đăng nhập tài khoản Spotify của bạn.
            

            

              Bước 2: Bấm nút Create App (Tạo ứng dụng).
            

            

              Bước 3: Điền tên ứng dụng (ví dụ: MusicCollectorStudio), mục Redirect URIs điền http://127.0.0.1:5000/callback, tích chọn Web API và bấm Save.
            

            

              Bước 4: Bấm vào mục Settings của App vừa tạo, bạn sẽ nhìn thấy Client ID và nút bấm View client secret. Copy 2 đoạn mã này.
            

          


          
👑 Phần 2: Lấy Cookie sp_dc (Nếu Có Tài Khoản Spotify Premium - Tải 320k Trực Tiếp)

          

            

              Bước 1: Đăng nhập tài khoản Spotify Premium trên trình duyệt máy tính tại https://open.spotify.com.
            

            

              Bước 2: Bấm phím F12 (hoặc chuột phải chọn Inspect / Kiểm tra), chuyển sang tab Application (hoặc Storage trên trình duyệt Firefox).
            

            

              Bước 3: Ở cột bên trái, mở mục Cookies ➡️ chọn https://open.spotify.com.
            

            

              Bước 4: Tìm dòng có tên sp_dc, nhấp đúp vào cột Value và copy toàn bộ chuỗi ký tự dài đó.
            

            

              Bước 5: Mở mục ⚙️ Cấu Hình Hệ Thống trên menu ➡️ tab Spotify Apps ➡️ bấm ➕ Thêm Spotify App ➡️ Dán thông tin và bấm ⚡ Test Thử rồi 💾 Lưu!
            

          

        


        
        

          

            
🍪 Tại Sao Cần Nạp YouTube Cookies?

            

              Khi máy chủ tải âm thanh từ YouTube với tần suất liên tục, YouTube sẽ chặn yêu cầu với lỗi Bot Detection hoặc mã lỗi 429 Rate Limit. Việc nạp Cookie xác thực phiên đăng nhập giúp hệ thống vượt qua 100% rào cản và tải bài hát ổn định vĩnh viễn.
            

          


          
🛠️ Các Bước Xuất File cookies.txt Chuẩn Netscape:

          

            

              Bước 1 - Cài Tiện Ích: Cài đặt tiện ích mở rộng xuất Cookie trên Chrome, Edge hoặc Firefox:
              
• Tiện ích khuyên dùng: Get cookies.txt LOCALLY (Mã nguồn mở, bảo mật, không gửi dữ liệu ra ngoài) hoặc Cookie-Editor.
            

            

              Bước 2 - Đăng Nhập: Mở trang web https://www.youtube.com trên trình duyệt và đăng nhập tài khoản Google của bạn.
            

            

              Bước 3 - Xuất File: Bấm vào biểu tượng tiện ích ở góc trên bên phải trình duyệt ➡️ Bấm Export (hoặc chọn định dạng Netscape) ➡️ Tải file cookies.txt về máy tính.
            

            

              Bước 4 - Nạp Vào Hệ Thống: Trên Dashboard, mở mục 🍪 Headless Cookies ở menu bên trái ➡️ Bấm ➕ Thêm Cookie Mới ➡️ Bấm 📁 Nạp Từ File .txt để chọn file vừa tải ➡️ Bấm ⚡ Test Thử để đo Ping ➡️ Bấm 💾 Lưu Vào Database.
            

          

          

            💡 Cơ Chế Bảo Vệ: Cookies được lưu vĩnh viễn trong MongoDB. Hệ thống có bộ giám sát tự động: Nếu Cookie hết hạn giữa chừng khi đang tải batch, hệ thống sẽ Tự động tạm dừng và gửi thông báo cảnh báo tức thì!
          

        


        
        

          

            
🛡️ Quản Trị Proxy Pool Đa Tầng

            

              Khi cần cào dữ liệu quy mô lớn hàng nghìn bài hát, Proxy giúp phân tán tải và thay đổi địa chỉ IP của máy chủ liên tục, tránh bị nghẽn mạng hay chặn IP từ các dịch vụ âm nhạc.
            

          


          
📋 Các Định Dạng Proxy Hỗ Trợ:

          
    
            
  • Giao thức: Hỗ trợ cả 3 giao thức phổ biến: HTTP, HTTPS, và SOCKS5.
    • 
            
  • Loại xác thực: Proxy mở (chỉ có Host & Port) hoặc Proxy có mật khẩu (Host, Port, Username, Password).
    • 
          


          
🛠️ Cách Cấu Hình & Đo Độ Trễ (Latency):

          

            

              1. Mở mục ⚙️ Cấu Hình Hệ Thống ➡️ chọn tab Proxy Pool.
            

            

              2. Bấm ➕ Thêm Proxy Mới, điền thông tin IP, Cổng, Giao thức.
            

            

              3. Bấm nút ⚡ Ping Thử để kiểm tra độ trễ (ms) thực tế từ máy chủ Oracle tới Proxy.
            

            

              4. Bật công tắc kích hoạt để đưa Proxy vào vòng xoay tự động.
            

          

        


        
        

          

            
🕷️ Trung Tâm Thu Thập & Cào Nhạc Đa Kênh

            

              Trang Sourcing Studio hỗ trợ quét nhạc đa nguồn với 6 chế độ thông minh và khả năng lọc xem trước bài hát trước khi lưu chính thức vào cơ sở dữ liệu.
            

          


          
🎯 6 Chế Độ Cào Linh Hoạt:

          

            

              📂 Theo Thể Loại Tuyển Chọn (Curated): Chọn nhanh trong 12 thể loại nhạc chuẩn (V-Pop, Ballad, Rap, Rock, EDM, Indie...). Hệ thống tự quét các playlist hàng đầu.
            

            

              🎤 Theo Tên Nghệ Sĩ: Nhập tên ca sĩ (ví dụ: Sơn Tùng M-TP, Đen Vâu). Hệ thống tự quét Top bài hát và toàn bộ các đĩa đơn, album.
            

            

              💿 Theo Album: Nhập tên Album để quét trọn vẹn danh sách bài hát theo số thứ tự track.
            

            

              🔍 Tìm Kiếm Từ Khóa: Nhập bất kỳ từ khóa bài hát nào bạn muốn tìm.
            

            

              🔗 Dán Đường Link (Spotify / Direct URL): Dán trực tiếp link bài hát hoặc playlist từ Spotify, YouTube, SoundCloud.
            

            

              🔥 Bảng Xếp Hạng Xu Hướng (Top Trends): Cập nhật theo thời gian thực BXH ZingMP3 Top 100, Nhaccuatui Top 20, Spotify Viral 50. Chỉ cần 1 click là nạp vào pipeline!
            

          


          
⚙️ 2 Chế Độ Thu Thập:

          

            

              🎵 Full Audio (Tải trọn gói MP3 320k + Lyrics): Vừa lưu metadata vào MongoDB, vừa xếp bài vào hàng đợi để tải toàn bộ file MP3 320k và lời karaoke về ổ cứng.
            

            

              📋 Metadata Only (Chỉ lấy siêu dữ liệu): Cào và lưu thông tin bài hát (tên, ca sĩ, album, năm, độ phổ biến, ảnh bìa) với tốc độ nhanh gấp 10 lần mà không tải file nhạc nặng.
            

          

        


        
        

          

            
🎵 Động Cơ Tải Âm Thanh MP3 320k & Lời Bài Hát

            

              Hệ thống tích hợp 2 engine hàng đầu: yt-dlp Engine và spotDL Engine với Node.js 20 & Deno runtime giải mã thuật toán chữ ký âm thanh tức thời.
            

          


          
🚀 Các Bước Khởi Chạy Tải Nhạc:

          

            

              1. Sau khi cào bài hát ở chế độ Full Audio, bài hát sẽ tự động xuất hiện trong Hàng đợi tải (Download Queue).
            

            

              2. Bấm nút ▶ Start Download trên thanh điều khiển hoặc góc phải trên cùng.
            

            

              3. Hệ thống sẽ tự động tải lần lượt các bài hát, trích xuất âm thanh Bitrate cao nhất (320 kbps MP3), nhúng ảnh bìa HD vào file, tự động tải lời bài hát .lrc và cập nhật trạng thái sang Completed.
            

            

              4. Bạn có thể bấm ⏸ Pause để tạm dừng hoặc ⏹ Stop bất cứ lúc nào mà không bị mất tiến trình.
            

          

        


        
        

          

            
📂 Quản Trị Kho Dữ Liệu & Khai Thác Âm Nhạc (Catalog Studio)

            

              Nơi quản lý toàn bộ kho bài hát đã thu thập với bộ lọc đa chiều, trình nghe thử nhạc trực tiếp và công cụ phân tích siêu dữ liệu chuyên sâu.
            

          


          
🎧 Các Tính Năng Nổi Bật:

          

            

              ▶ In-App Audio Player: Bấm nút Play ở đầu mỗi dòng bài hát để nghe thử trực tiếp file MP3 320k phát từ máy chủ. Có thanh tua sóng nhạc và hiển thị ảnh bìa xoay.
            

            

              🔍 Thanh Tra Siêu Dữ Liệu (Metadata Inspector): Bấm nút kính lúp để mở bảng phân tích:
              
• Visual Tab: Xem ảnh bìa, mã ISRC, độ dài ms, thể loại, độ phổ biến, album liên kết.
              
• Raw JSON: Xem toàn bộ cấu trúc Document JSON lưu trong MongoDB.
              
• ID3 Tags: Xem các frame nhúng trong file MP3 (TIT2, TPE1, APIC...).
              
• Quick Edit: Sửa nhanh thông tin bài hát và lưu lại ngay lập tức.
            

            

              📝 Biên Tập Lời Bài Hát (Lyrics Editor): Bấm nút ghi chú để xem và chỉnh sửa lời bài hát Karaoke .lrc có khớp mốc thời gian từng giây.
            

            

              📤 Xuất Báo Cáo Dữ Liệu: Bấm nút Export CSV hoặc Export JSON ở góc trên bảng để tải toàn bộ dữ liệu về phục vụ huấn luyện mô hình AI hoặc viết báo cáo đồ án.
