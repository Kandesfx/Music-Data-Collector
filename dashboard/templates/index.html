              🛡️ HƯỚNG DẪN SỬ DỤNG CLOUDFLARE WARP & PROXY POOL
            

            

              Khi cần cào dữ liệu quy mô lớn hàng nghìn bài hát, Proxy giúp phân tán tải và thay đổi địa chỉ IP của máy chủ liên tục, tránh bị nghẽn mạng hay chặn IP từ các dịch vụ âm nhạc.
            

          


          

            

              1. Cloudflare WARP Anycast Gateway (Khuyến nghị dùng mặc định):

              • Đã được cài đặt và cấu hình sẵn trên máy chủ Oracle Cloud chạy ở cổng SOCKS5 cục bộ 127.0.0.1:40000.

              • Hoàn toàn miễn phí, băng thông vô hạn, độ trễ cực thấp (~250ms), ẩn IP Datacenter Oracle sang dải IP Anycast 104.28.x.x của Cloudflare.

              • Điều khiển: Vào ⚙️ Cài Đặt ➡️ Tab 🌐 Ẩn IP & WARP Shield để xem huy hiệu bảo vệ màu xanh 🟢 hoặc bấm Bật/Tắt 1-Click.
            

            

              2. Nạp thêm Proxy Dân Cư ngoài (Residential Proxies):

              • Hỗ trợ mọi giao thức: HTTP, HTTPS, SOCKS4, SOCKS5 (có User/Pass hoặc xác thực theo IP).

              • Cách nạp: Vào ⚙️ Cài Đặt ➡️ Tab 🛡️ Proxy Pool & Ping ➡️ Bấm ➕ Thêm Proxy Mới ➡️ Nhập Host, Port ➡️ Bấm ⚡ Ping Thử ➡️ Bấm 💾 Lưu.
            

            

              3. 4 Chiến Lược Xoay Vòng Proxy Thông Minh:

              • 🔄 Round-Robin: Luân chuyển tuần tự qua từng Proxy trong danh sách.

              • ⚡ Lowest-Latency: Luôn tự động chọn Proxy có thời gian phản hồi Ping thấp nhất.

              • 🛡️ Failover-Only: Ưu tiên sử dụng Cloudflare WARP, chỉ tự động kích hoạt Proxy dự phòng khi phát hiện mạng lỗi.

              • 🎲 Random: Chọn ngẫu nhiên một Proxy cho mỗi bài hát được tải.
            

            

              4. 🎭 Bảng Điều Khiển Hồ Sơ Dấu Vân Tay (Fingerprint Studio v4.0):

              • Dựa trên kiến trúc của browser-forge, curl_cffi, và playwright-stealth: Tự động đồng bộ hóa tương quan 100% giữa User-Agent, Sec-CH-UA Client Hints, WebGL GPU context (NVIDIA RTX / Apple M3 / AMD RX), Độ phân giải màn hình & DPI, Phần cứng CPU/RAM, Chữ ký TLS JA4, và YouTube InnerTube Player Client.

              • Vào ⚙️ Cài Đặt ➡️ Tab 🌐 Ẩn IP & WARP Shield ➡️ Mục 🎭 Browser Fingerprint Studio để chuyển đổi giữa 8 hồ sơ mẫu (Windows 11 Chrome/Edge/Firefox, macOS Safari/Chrome, iPhone 16 Pro Max, Samsung Galaxy S24, Smart TV Tizen) hoặc bấm ⚡ Audit Dấu Vân Tay để kiểm tra 7 điểm vượt bot!
